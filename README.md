# Deeksha Gunde — AIML-500 Portfolio

## Structure
```
index.html                 Home: bio, value proposition, target audience, artifact grid, contact
artifacts/artifact-1.html  Artifact page template (copy for each new artifact)
assets/style.css           All styling
assets/img/                Screenshots
assets/files/              PDFs, slides, downloads (resume.pdf goes here too)
```

## Preview while drafting (private)
Unzip the folder and double-click `index.html`. It opens in your browser with no hosting needed.

## Adding an artifact
1. Copy `artifacts/artifact-1.html` → `artifact-2.html`, then fill in every [placeholder].
2. Drop its screenshot into `assets/img/` and the deliverable into `assets/files/`.
3. On `index.html`, replace the matching "Coming soon" card with a real card.
4. Submit the reflection in Brightspace (not on the site).

Search for `EDIT` in index.html to find the spots to personalize.
